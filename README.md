# Audio Visualizer

Visualisiert Audio der Musikdateien in src/main/resources/com/example/visualizer1

## Starten
Java 21 und Maven installieren, dann im Projektordner:
mvn javafx:run


## Hinweise für Linux
Getestet unter Linux Mint mit dem Wayland-Compositor Niri.
Dort hat der Button zunächst nicht auf Mausklicks reagiert.
Lösung: Das Programm mit der Option -Djdk.gtk.version=3 starten.
